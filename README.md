# Zarządzanie połączeniami kolejowymi

Prosta aplikacja desktopowa napisana w **C#**, służąca do zarządzania połączeniami kolejowymi.

## Funkcje

* dodawanie, edycja i usuwanie stacji,
* przeglądanie dostępnych połączeń,
* obsługa danych z wykorzystaniem bazy **MySQL/MariaDB**.

## Technologie

* **C# / .NET**
* **MySQL / MariaDB**
* **ODBC**

## Cel projektu

Projekt został stworzony w celu praktycznego wykorzystania programowania obiektowego, obsługi bazy danych oraz tworzenia aplikacji w C#.
